## ✨ نبذة عن المشروع

**GhostImage** هي أداة احترافية لتحليل الصور واستخراج البيانات الوصفية (Metadata) والكشف عن التلاعب والتشفير المخفي داخل الملفات.

- 🖼️ **تحليل كامل** للصور (JPEG, PNG, GIF, BMP, WEBP)
- 📡 **استخراج GPS** وإحداثيات الموقع
- 🔐 **حساب الهاش** (MD5, SHA256)
- 📊 **إحصائيات البكسل** والقنوات اللونية
- 📝 **تقارير PDF** احترافية
- 🔒 **تشفير آمن** — الكود محمي ولا ينفك إلا عند التشغيل

---

## 🚀 التشغيل السريع

### المتطلبات
```bash
pip install Pillow exifread requests reportlab
```

### التشغيل
```bash
# النسخة المشفرة (الموصى بها)
python3 GhostImage_encrypted_v2.py

# أو النسخة العادية
python3 GhostImage.py
```

---

## 📂 الملفات

| الملف | الوصف |
|-------|--------|
| `GhostImage_encrypted_v2.py` | 🔐 النسخة المشفرة — آمنة ومتوافقة مع كل الإصدارات |
| `GhostImage_encrypted.py` | 🔒 النسخة المشفرة الأولى (marshal) |
| `GhostImage.py` | 📄 النسخة الأصلية مفتوحة المصدر |

## 🛡️ مميزات الأمان

- ✅ **تشفير XOR ديناميكي** مع Salt عشوائي
- ✅ **ضغط zlib** للحماية الإضافية
- ✅ **كود المصدر مخفي** — يترجم في وقت التشغيل فقط
- ✅ **مقاومة للتعديل** — يتحقق من `__main__`
